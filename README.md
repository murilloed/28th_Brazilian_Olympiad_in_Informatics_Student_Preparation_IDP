# OBI 2026 - Preparacao De Alunos IDP

Este repositorio organiza materiais de preparacao para a Olimpíada Brasileira de Informática 2026 (OBI), com foco nos alunos do Instituto Brasileiro de Ensino, Desenvolvimento e Pesquisa (IDP).

Site oficial da OBI: <https://olimpiada.ic.unicamp.br/>

## Objetivo

Organizar materiais de estudo, treino, listas, simulados, calendarios, instrucoes e documentos de apoio para os alunos participantes da OBI 2026.

## Publico

Alunos do primeiro periodo universitario do IDP inscritos na:

```text
Modalidade: Programacao
Nivel: Senior
Codigo: PS
Ano Escola: U1
```

## Linguagem De Treino

A linguagem principal de treino do IDP passa a ser:

```text
Python
```

A OBI permite submissao em:

- C
- C++
- Java
- Python

Mesmo com outras linguagens permitidas, a equipe treinara com foco em Python para ganhar velocidade de implementacao, reduzir erros de sintaxe e concentrar energia na interpretacao dos enunciados e na logica dos algoritmos.

## Estrategia De Preparacao

A preparacao sera pratica, com foco em:

- entrada e saida com `input()`, `split()`, `map()` e `sys.stdin`;
- condicionais;
- lacos;
- listas;
- strings;
- simulacao;
- matematica basica;
- problemas antigos da OBI;
- simulados com tempo;
- correcao de erros comuns em Python.
