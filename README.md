# 28th_Brazilian_Olympiad_in_Informatics_Student_Preparation
Repository containing study materials, algorithms, programming exercises, challenge solutions, and preparation resources for students participating in the 28th Brazilian Olympiad in Informatics (OBI). Designed to support logical reasoning, problem-solving skills, and competitive programming training.
