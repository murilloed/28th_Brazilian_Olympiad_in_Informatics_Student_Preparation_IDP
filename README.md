# OBI 2026 - Preparação De Alunos IDP

Este repositório organiza materiais de preparação para a Olimpíada Brasileira de Informática 2026 (OBI), com foco nos alunos do Instituto Brasileiro de Ensino, Desenvolvimento e Pesquisa (IDP).

Site oficial da OBI: <https://olimpiada.ic.unicamp.br/>

## Objetivo

Organizar materiais de estudo, treino, listas, simulados, calendários, instruções e documentos de apoio para os alunos participantes da OBI 2026.

## Público

Alunos do primeiro período universitário do IDP inscritos na:

```text
Modalidade: Programação
Nível: Sênior
Código: PS
Ano Escola: U1
```

## Linguagem De Treino

A linguagem principal de treino será:

```text
C
```

A OBI permite:

- C
- C++
- Java
- Python

Mas a equipe do IDP estudará inicialmente com foco em C.

## Estratégia De Preparação

A preparação será prática, com foco em:

- entrada e saída;
- condicionais;
- laços;
- vetores;
- strings;
- simulação;
- matemática básica;
- problemas antigos da OBI;
- simulados com tempo;
- correção de erros comuns em C.
