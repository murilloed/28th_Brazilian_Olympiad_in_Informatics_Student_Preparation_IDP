# Links Oficiais - OBI 2026

Este arquivo reúne links úteis para consulta, inscrição, prática, calendário e regulamento da Olimpíada Brasileira de Informática 2026.

## 1. Site Oficial

Página principal da OBI:

<https://olimpiada.ic.unicamp.br/>

Use para acessar notícias, informações gerais, calendário, resultados, regulamento e área de competidores.

## 2. Calendário

Calendário oficial da OBI:

<https://olimpiada.ic.unicamp.br/calendario/>

Use para consultar:

- datas de inscrição;
- datas das fases;
- datas da Competição Feminina;
- Semana Olímpica;
- eventos relacionados.

## 3. Datas Importantes

Página de datas importantes:

<https://olimpiada.ic.unicamp.br/info/datas-importantes/>

Use para conferir prazos como:

- cadastro da escola;
- inscrição de competidores;
- Fase Local;
- Fase Estadual;
- Fase Nacional;
- CF-OBI.

## 4. Regulamento

Regulamento oficial:

<https://olimpiada.ic.unicamp.br/info/regulamento/>

- modalidades;
- níveis;
- elegibilidade;
- regras de inscrição;
- regras de prova;
- linguagens permitidas;
- critérios de classificação;
- premiação.

## 5. Área De Prática

Página de prática:

<https://olimpiada.ic.unicamp.br/pratique/>

## 7. Acesso Para Competidores

Página principal da OBI:

<https://olimpiada.ic.unicamp.br/>

No menu superior, usar a opção de acesso/entrada para competidores quando disponível.

Use para:

- acessar página pessoal;
- consultar inscrição;
- acessar ambiente de prova;
- verificar resultados.

## 8. Acesso Para Escolas / Coordenador Local

Página principal da OBI:

<https://olimpiada.ic.unicamp.br/>

No menu superior, usar a opção de entrada para escolas/coordenadores quando disponível.

Use para:

- cadastrar escola;
- inscrever competidores;
- enviar planilha de inscrição em lote;
- acompanhar inscrições;
- registrar informações necessárias.

## 9. Competição Feminina Da OBI

Página principal da OBI:

<https://olimpiada.ic.unicamp.br/>

Use o menu da OBI para localizar informações atualizadas sobre a CF-OBI.

Observação:

Para as alunas universitárias do IDP, é importante confirmar se há enquadramento permitido na CF-OBI 2026, pois o regulamento analisado lista níveis até Programação Nível 2, não Programação Sênior.

## 13. Observações

- Sempre conferir as datas no site oficial antes de aplicar provas ou enviar inscrições.
- O calendário pode ter atualizações.
- A inscrição dos alunos deve ser feita pelo Coordenador Local.
- Para alunos do primeiro período universitário, a modalidade correta é Programação Sênior (`PS`) e o ano escola é `U1`.
- A prova é individual.
- A linguagem de treino do IDP será Python.
