## 3. Como Sera A Prova

- Prova individual.
- Resolucao no computador.
- Correcao automatica por testes.
- Cada tarefa pode ter pontuacao parcial.
- O professor pode treinar antes, mas nao pode ajudar durante a prova.

## 4. Linguagens Permitidas

A OBI permite C, C++, Java e Python. A equipe IDP treinara em Python.

## 5. Por Que Python?

Python e adequado para esta preparacao porque:

- e aceito oficialmente;
- permite codigo mais curto;
- facilita listas, strings e ordenacao;
- reduz erros mecanicos de sintaxe;
- ajuda os alunos a focarem em logica, leitura e testes.

## 7. Lista E Soma

```python
n = int(input())
valores = list(map(int, input().split()))

soma = 0

for x in valores:
    soma += x

print(soma)
```

## 10. Erros Comuns Em Python

- esquecer `int()` na entrada numerica;
- esquecer `split()` para varios valores na mesma linha;
- errar indentacao;
- esquecer `:`;
- imprimir texto extra;
- acessar lista fora do limite;
- usar `/` quando precisava de `//`;
- nao testar casos extremos.
