## 6. Como sera a prova da OBI principal

Para as alunas do IDP em Programacao Senior:

- a prova e individual;
- e realizada no computador;
- e presencial na instituicao na Fase Local;
- deve ser resolvida sem ajuda durante a prova;
- as linguagens permitidas sao C, C++, Java e Python;
- a correcao e por testes automaticos;
- cada tarefa pode valer ate 100 pontos;
- a Fase Local tem duracao de 2 horas;
- a Fase Estadual tem duracao de 3 horas;
- a Fase Nacional de Programacao Senior ocorre das 13h as 18h.

## 10. Modelo dos simulados

```text
2h - simulado individual
40 min - correcao dos problemas
20 min - discussao de estrategia e erros
```

Durante o simulado:

- nao conversar;
- nao usar internet;
- testar com os exemplos;
- criar testes proprios;
- controlar tempo;
- priorizar os problemas mais faceis.

## 11. Estrategia de prova

1. Ler rapidamente todos os problemas.
2. Escolher primeiro o problema mais facil.
3. Resolver com calma e testar.
4. Conferir formato de saida.
5. Submeter.
6. Nao travar muito tempo em um unico problema.
7. Se nao conseguir solucao completa, tentar uma solucao parcial correta.
8. Usar o tempo final para revisar erros simples.

## 12. Erros comuns em C que devem ser evitados

### Esquecer o `&` no `scanf`

Errado:

```c
scanf("%d", n);
```

Correto:

```c
scanf("%d", &n);
```

### Passar do limite do vetor

Errado:

```c
for (int i = 0; i <= n; i++) {
    scanf("%d", &v[i]);
}
```

Correto:

```c
for (int i = 0; i < n; i++) {
    scanf("%d", &v[i]);
}
```

### Usar `int` quando precisa de `long long`

```c
long long x;
scanf("%lld", &x);
printf("%lld\n", x);
```

### Comparar string com `==`

Errado:

```c
if (nome == "MARIA")
```

Correto:

```c
#include <string.h>

if (strcmp(nome, "MARIA") == 0)
```
