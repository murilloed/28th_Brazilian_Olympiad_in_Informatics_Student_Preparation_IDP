# Simulados - OBI 2026

Esta pasta organiza simulados para a preparação da equipe do IDP.

Os simulados devem reproduzir o ambiente da prova o máximo possível.

## Objetivo

Treinar:

- tempo de prova;
- leitura rápida de enunciados;
- escolha de problemas;
- implementação sob pressão;
- testes;
- submissão;
- correção pós-prova.

## Formato Recomendado

Para a Fase Local de Programação Sênior:

```text
Duração: 2 horas
Formato: individual
Linguagem de treino: C
Quantidade sugerida: 3 problemas
```

## Regras Do Simulado

Durante o simulado:

- não conversar;
- não usar internet;
- não olhar solução pronta;
- não pedir ajuda ao professor;
- testar apenas com exemplos e testes próprios;
- controlar o tempo;
- registrar a solução final.

## Estrutura De Cada Simulado

Criar uma pasta para cada simulado:

```text
simulado_01/
  enunciados.md
  solucoes/
  gabarito_comentado.md
  resultados.md
```

## Modelo De Agenda Do Simulado

```text
00:00 - início
00:10 - leitura dos problemas
00:20 - começar pelo problema mais fácil
01:20 - revisar soluções submetidas
01:50 - últimos testes
02:00 - fim do simulado
02:00-03:00 - correção comentada
```


## Correção Do Simulado

Após o simulado, registrar:

- problemas resolvidos;
- problemas não resolvidos;
- erros de compilação;
- erros de lógica;
- problemas de interpretação;
- tempo gasto por problema;
- pontuação estimada;
- o que revisar antes da prova.

## Frase De Orientação

> O simulado não serve apenas para medir acertos. Ele serve para descobrir erros antes da prova oficial.
