# Lista De Exercícios - Programação Nível 2

Esta pasta reúne exercícios intermediários para preparação da equipe do IDP.

O Nível 2 é importante porque aproxima os alunos de problemas mais parecidos com os desafios que podem aparecer no Nível Sênior.

## Objetivo

Treinar:

- interpretação de enunciados maiores;
- vetores;
- strings;
- ordenação;
- busca;
- frequência;
- simulação;
- matemática discreta simples;
- estratégia de solução parcial.

## Como Usar

1. Acesse:

   <https://olimpiada.ic.unicamp.br/pratique/>

2. Escolha:

   ```text
   Modalidade Programação
   Nível 2
   ```

3. Resolva primeiro os problemas mais fáceis.

4. Depois tente problemas médios.

## Ordem Recomendada

1. Problemas de simulação.
2. Problemas com vetores.
3. Problemas com strings.
4. Problemas com ordenação.
5. Problemas com busca.
6. Problemas com contagem e frequência.
7. Problemas com matemática simples.

## Estratégia Para O Nível 2

Antes de programar:

```text
1. Entender a entrada.
2. Entender a saída.
3. Fazer exemplo no papel.
4. Pensar na solução mais simples.
5. Verificar se a solução passa nos limites.
6. Só então programar.
```

## Checklist Do Nível 2

O aluno está evoluindo quando consegue:

- resolver problemas sem olhar solução;
- identificar se precisa de vetor, string ou ordenação;
- controlar tempo de prova;
- evitar erros de índice;
- explicar complexidade básica;
- conseguir pontuação parcial em problemas mais difíceis.
