# Lista De Exercícios - Programação Nível Sênior

Esta pasta reúne exercícios do Nível Sênior, antigo Universitário.

Este é o nível oficial dos alunos do IDP na OBI 2026.

## Modalidade Oficial

```text
Modalidade: Programação
Nível: Sênior
Código: PS
Ano Escola: U1
```

## Objetivo

Treinar problemas no nível real da prova dos alunos.

Os exercícios podem exigir:

- boa interpretação;
- implementação cuidadosa;
- vetores;
- strings;
- ordenação;
- busca;
- simulação;
- matemática;
- estruturas de dados básicas;
- raciocínio algorítmico mais forte.

## Como Usar

1. Acesse:

   <https://olimpiada.ic.unicamp.br/pratique/>

2. Escolha:

   ```text
   Modalidade Programação
   Nível Sênior antigo Universitário
   ```

3. Escolha problemas de anos anteriores.

4. Resolva com tempo controlado.

## Estratégia Para O Nível Sênior

No início, não é obrigatório resolver tudo.

Meta realista:

- resolver problemas mais acessíveis;
- tentar pontuar parcialmente nos médios;
- aprender a reconhecer problemas difíceis;
- não travar em um único problema;
- melhorar leitura e implementação.

## Ordem De Treino

1. Resolver problemas fáceis do Sênior.
2. Refazer problemas errados.
3. Comparar com problemas do Nível 2.
4. Fazer simulados de 2 horas.
5. Estudar os temas que mais aparecem.

## Checklist Do Nível Sênior

Antes da prova, cada aluno deve conseguir:

- resolver pelo menos alguns problemas antigos;
- implementar soluções em C sem travar no básico;
- testar exemplos;
- criar casos de teste;
- decidir quando abandonar temporariamente um problema;
- buscar pontuação parcial;
- controlar o tempo.
