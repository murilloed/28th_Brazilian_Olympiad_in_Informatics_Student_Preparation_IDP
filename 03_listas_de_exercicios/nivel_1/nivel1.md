# Lista De Exercícios - Programação Nível 1

Esta pasta reúne exercícios introdutórios para alunos que estão começando a treinar para a OBI.

Mesmo que a equipe do IDP esteja inscrita em Programação Sênior, o Nível 1 é recomendado para aquecimento, domínio de entrada/saída e construção de confiança.

## Objetivo

Treinar:

- leitura de entrada;
- impressão de saída;
- condicionais;
- laços;
- contadores;
- acumuladores;
- vetores simples;
- lógica básica.

## Como Usar

1. Acesse a área de prática da OBI:

   <https://olimpiada.ic.unicamp.br/pratique/>

2. Escolha:

   ```text
   Modalidade Programação
   Nível 1
   ```

3. Resolva problemas de anos anteriores.

4. Para cada problema, registre:

   - nome do problema;
   - ano;
   - link;
   - nível de dificuldade;
   - solução em C;
   - erros cometidos;
   - observações.

## Ordem Recomendada

Comece por problemas que envolvam:

1. soma e operações básicas;
2. par ou ímpar;
3. maior e menor;
4. contagem;
5. simulação simples;
6. vetores pequenos;
7. strings simples.

## Checklist Do Nível 1

O aluno está pronto para avançar quando conseguir:

- ler e imprimir dados sem erro;
- usar `if` e `else`;
- usar `for` e `while`;
- resolver problemas simples sem ajuda;
- testar com exemplos;
- criar testes próprios;
- explicar a própria solução.
